# Дальнейшее развитие

## Семейный пилот

Первый этап: один профиль Амели, серверное хранение, перенос из прототипа, добавление тем наборами, резервные копии, главная с бумажной иллюстрацией и четыре новых слова в день по умолчанию. Взрослый может снизить число до одного или двух. Существующий прогресс не сбрасывается.

Перед публикацией нужно выбрать проект Railway, настроить диск и семейный доступ, затем проверить озвучку на устройстве Амели. Учебник: Spotlight, 2 класс, часть 1; текущее место — страницы 66–68. В первом классе английского не было. Вводный маршрут строим с нуля через интересы Амели, со свободной связью со школьными темами. Подробности — в [плане вводных занятий](learning-plan.md).

## Методика и интерес

Учебник использовать как ориентир для последующего переноса знакомых слов в школьные задания. Основной порядок: узнавание на слух и простые фразы, затем чтение и письмо. Начать с малого числа слов, без оценок, обязательных серий и наказаний за пропуски. Проверять, помогает ли ребёнку занятие, а не только растёт ли число звёзд. Не требовать знания алфавита или сборки слов по буквам для доступа к первым занятиям.

Превратить рисование и айкидо в небольшие сюжетные задания: помочь персонажу собрать коробку красок, раскрасить открытку, понять знакомую команду на тренировке. Развить единую систему аппликаций для слов, персонажей и наград. Новая иллюстрация на главной показывает направление; полный набор карточек пока использует эмодзи.

По пожеланию мамы Амели добавлена отдельная [привязка к учебнику](homework.md): взрослый задаёт страницы и слова, они получают приоритет в интервальных повторениях. Это дополняет маршрут с нуля и не требует прохождения учебника в фиксированном порядке.

Отчёт взрослому: что узнаёт на слух, что повторяет с подсказкой, какие слова требуют возвращения. Сейчас доступны количество карточек, темы, повторения, рисунки и звёзды; это не диагностика уровня владения языком.

## Библиотека контента и генерация

Хранить тематические наборы с уровнем, целевыми фразами и правами на изображения. Добавить черновик → проверку взрослым → публикацию; затем генерацию через серверный API с ограничением стоимости. Не отправлять имя, историю занятий или другие данные ребёнка генератору без конкретной необходимости и согласия взрослого.

## Несколько семей и монетизация

Перед продажами нужны отдельные аккаунты взрослых, изоляция детских профилей и данных, роли, восстановление доступа, удаление/экспорт данных и регулярные проверяемые резервные копии. Общий семейный пароль этой версии для этого не подходит. После нескольких пилотов можно проверить спрос на тематические пакеты по интересам детей и только затем добавлять оплату и подписки.
