# Шрифты

Локальные копии шрифтов из пакетов Fontsource версии 5.3.0:

- `@fontsource/pangolin`: Pangolin, начертание 400, latin и cyrillic.
- `@fontsource/andika`: Andika, начертания 400 и 700, latin и cyrillic.
- `@fontsource-variable/nunito`: Nunito Variable, normal, latin и cyrillic.

Архивы получены через npm с обычной проверкой целостности. Использованы оригинальные WOFF2 без изменений; CSS с Unicode-диапазонами сохранён в `css/fonts.css`. Лицензия каждого шрифта SIL Open Font License 1.1 находится в `assets/fonts/*-LICENSE.txt`. Обращения к Google Fonts при открытии приложения больше не нужны.

Иллюстрация `assets/studio-cat.webp` создана специально для этого прототипа с помощью генератора изображений, затем перекодирована в WebP для веба. Это первый вариант визуального направления, а не готовый набор иллюстраций для всех слов.
