# Amelie's Art Studio 🎨

Английский для Амели: короткие занятия через рисование, игры и айкидо. Серверный выпуск рассчитан на одну семью: отдельные входы родителя и Амели, два независимых тестовых альбома.

## Разработка

Нужен Node.js 24. Внешних npm-зависимостей нет; SQLite входит в Node.js.

```sh
npm ci
npm run dev
```

Сервер по умолчанию слушает только `127.0.0.1:3000`. Откройте этот адрес в браузере на своей машине. База создаётся в `.local/amelie.sqlite`, а темы и слова загружаются из `data/*.json` только при первом запуске. Не удаляйте базу при обновлениях. С `APP_USER` и `APP_PASSWORD` включается семейная авторизация: `parent` с прежним `APP_PASSWORD`, отдельные базы детей в `.local/profiles/`, учётные записи в `.local/accounts.sqlite`. Детские пароли выдаёт взрослый внутри приложения. Без этих переменных локальная разработка сохраняет прежний режим одного профиля.

```sh
npm test
python3 tests/browser_smoke.py
```

Вторая команда — проверка настоящим браузером, требует Python Playwright и Chromium. В облачной среде разработки они уже установлены. Иной путь к Chromium можно передать переменной `CHROMIUM_PATH`.

Старый режим GitHub Pages продолжает работать без Node.js: статические файлы и `localStorage`. Для его локальной проверки: `python3 -m http.server 8000`. Не используйте статический сервер для публикации всего рабочего каталога с приватной базой; серверный вариант раздаёт только разрешённые публичные файлы.

Сервер подтверждает запись в SQLite; при временной ошибке отправки браузер сохраняет очередь на этом устройстве и повторяет запрос. Статус сохранения виден взрослому. Это не полноценный офлайн-режим: первоначальная загрузка серверной версии требует связи.

Файлы `.env`, `.local/`, SQLite и резервные копии исключены из Git и сборки контейнера. Никакие данные ребёнка не отправляются во внешнюю систему аналитики или генерации. Озвучка использует установленный в браузере английский голос; её нужно проверить на устройстве Амели.
