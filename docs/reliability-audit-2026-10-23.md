## Что хранится в базе

Для каждого ребёнка отдельный `/data/profiles/<profile>.sqlite`.

- `records/words`, `records/topics`: стабильный словарь. Обновление формулировки по тому же id не удаляет карточку. Новый id — новая карточка.
- `records/progress`: уровень, срок следующего показа, число ответов, последний ответ и день успешного продвижения.
- `records/log`: каждый ответ с уникальным id, словом, временем, результатом, признаком первого знакомства и необязательным заданием.
- `records/profile`: звёзды, все наклейки, дневные шаги, настройки и ленивый checkpoint новых порогов.
- `records/gallery`: исходные сохранения рисунков, версии контуров и цвета отдельных деталей.
- `records/assignments`: книга, печатные страницы, текст, срок, стабильные id слов, необязательная раскраска и признак завершения.
- `activity_events`: квитанции обработанных действий. Один id применяется один раз; конфликтующее тело с тем же id отвергается.
- `meta`: первичное наполнение и маркер однократного переноса. Обычный запуск и обновление кода не пересоздают словарь и не повторяют импорт ребёнка.

`accounts.sqlite` содержит хеши паролей и сессий. Он не входит в JSON прогресса, но входит в закрытые семейные SQLite-копии.

Браузер сохраняет неподтверждённые действия в очереди своего аккаунта/профиля. Подтверждение потерялось — запрос повторяется с тем же id. Серверное состояние сверяется с оптимистическим после очереди. Отказ localStorage виден как предупреждение; нельзя обещать сохранение после закрытия вкладки, если не подтвердил ни сервер, ни локальное хранилище. Выход/переключение альбома ждут подтверждения. Новый словарь, настройка голоса или задание не переписывают достижения.

## Проверки

- `npm test`: 22 проверки — SQLite, HTTP, права/изоляция, транзакции, контент, старые и новые экспорты, миграция, параллельные действия, квитанции, награды, копирование и восстановление.
- `python3 tests/browser_smoke.py`: сервер и статическая версия; 110 слов, темы на 320/390 px, карточки, SRS и домашняя работа, игры, ABC, раскраски, импорт/экспорт, локальная очередь и сбой сервера.
- `python3 tests/family_journey_browser.py`: потерянный ответ после commit, два контекста, неверный ввод, публикация шаблона, школьное меню и прослушивание без изменения расписания, листы наклеек, быстрые клики и отмена раунда, статус автокопии.
- `python3 tests/colouring_details_browser.py`: самостоятельные цвета деталей, пустые/повторные сохранения, новые варианты, смешанная галерея старых и новых контуров.

Перед production — отдельная закрытая копия всех профилей. После — проверка опубликованных файлов/версии, школьного меню, альбома наклеек, родительского статуса копии и точное сравнение пяти коллекций личного состояния (`progress`, `log`, `profile`, `gallery`, `assignments`). Новые поля полного экспорта сравниваются отдельно: расширение файла не означает изменение достижений.

## Практические пределы

Проверки браузера выполнены в Chromium. Качество системного английского голоса, поведение Safari/iOS и удобство восьмилетнего ребёнка нужно дополнительно наблюдать на её устройстве. Автоматический тест не подтверждает педагогический эффект.

Дневные копии сейчас находятся на том же Railway Volume. Внешняя выгрузка ещё не настроена; отдельно скачанный полный JSON защищает содержимое выбранного альбома, семейный SQLite-снимок — также доступы. Фото/PDF внутри приложения, AI-распознавание, фоновые AI-задания и отправка уведомлений не реализованы. Платные API не включены. Варианты и условия — в [семейном сценарии](parent-workflow.md) и [расчёте бюджета](generation-budget.md).
