# Иллюстрации и фактура

`assets/paper-friends.webp` — набор из девяти иллюстраций, сгенерированный по двум пользовательским листам референсов: кот, книга, мяч, бабочка, собака, рюкзак, кролик, самолёт, кораблик. Прозрачный фон, тёплый контур, вырезанная и окрашенная акварельная бумага. Прямоугольники в `paperArt()` учитывают фактическое расположение рисунков; общее изображение загружается один раз.

`assets/watercolor-paper.webp` — сгенерированная фактура хлопковой акварельной бумаги. Используется под светлым слоем на карточках и под цветным слоем на картоне. `assets/studio-cat.webp` — ранее подготовленный герой мастерской.

Чтобы добавлять рисунки через этот чат, достаточно описать тему и слова. Для нового стиля пригодятся референсы; для продолжения этого стиля можно использовать существующие ресурсы репозитория. Для карточек важны точное соответствие слову, читаемый силуэт, прозрачность и одинаковый масштаб. Не связывайте случайную картинку с глаголом или предметом с другим значением.
